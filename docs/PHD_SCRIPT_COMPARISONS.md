## CPython xfail groups (pytest)

`10 xfailed`, `11 passed`, `22 skipped` on `test_phd_jython_scripts.py` (after file-compare + harness fixes). Grouped by root cause:

| Root cause | Scripts | First divergence |
|------------|---------|------------------|
| **Rust/Java nullary parse parity** | `probes/nullary_string_to_term.py` | stdout L2: `jython='parse_fail\|e()\|empty string'` `cpython='parse_ok\|e()\|term:e()'` |
| **Upset-lattice `join` table on CPython (pre-arrow residuation)** | `heyting_from_poset.py` | `input/d3_dual.ua` line 31: Jython `join` row `[1]` all `1`; CPython shows identity row `1,1,2,3,4,5` |
| **Mace4 stream → `BasicAlgebra` coercion on CPython** | _(fixed)_ | Was `ValueError` building nullary ops with `set_size=1`; now uses algebra cardinality like `Mace4Reader` |
| **Jamie `BasicAlgebra` + `findFailureMap`** | _(fixed)_ | `associativity_of_iff.py`, `check_heyting.py`, `sums.py`, `mace4.py`, `filter2sa_mace4.py` |
| **Failure map key stringification** | `check_m.py` | stdout L1: `fails at {x: 1}` vs `{VariableImp("x"): 1}` |
| **Glob / filesystem side effects** | `2subalgebras.py` | L12: extra path line `...\input\C-5-11.ua` on CPython (13 vs 11 lines) |
| **Search vs delete diagnostics** | `find_simple_chains.py` | stdout L2: `found example 244` vs `C-{5}-{1} deleting ...C-5-1.ua` |

### Roadmap (from xfail groups)

1. **`findFailureMap` + Jamie algebras:** accept `dmm.BasicAlgebra` (coerce via temp `.ua` round-trip or extend Rust binding) so `check_heyting`, `associativity_of_iff`, `sums`, and heyting dual write + check pass.
2. **Nullary `e()`:** align `Terms.stringToTerm` with Java or document intentional Rust extension (probe).
3. **Mace4 `to_alg`:** fix `AbstractOperation` / cardinality handling when building from parsed tables on CPython; then enable pass on `input/KR-1gen-1.ua` file golden.
4. **`findFailureMap` print format:** normalise variable keys in failure messages (`check_m`).
5. **2subalgebras / find_simple_chains:** align glob expansion and diagnostic prints with Jython golden normalization.
